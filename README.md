# ضوئيات — Dawiyat

برنامج مجاني بالعربي والإنجليزي لتعلّم شبكات الألياف الضوئية FTTH / GPON: دروس، ومختبرات عملية، وتجهيز للشهادات الاحترافية. يعمل بدون إنترنت.

A free Arabic/English app for learning FTTH / GPON fiber networks: lessons, hands-on labs and certification prep. Works offline.
